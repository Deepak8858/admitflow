# AdmitFlow UI and entry-route audit — 26 September 2026

## Outcome and scope

The existing landing page now owns `/`; `/welcome` remains an alias. The private workspace starts at `/overview`. All twelve workspace routes are explicitly validated, have individual page titles and remain excluded from search indexing. Invalid and nested paths return a recovery-oriented 404 without mounting the workspace client.

Public navigation connects the landing page, Product, Pricing and a new five-step Help guide, including a mobile menu. Sign-in callback failures have a dedicated retry page. Public routes do not load workspace data or AuthKit session state. Pricing explains the unpublished commercial terms instead of presenting a billing-period switch that changes no plan.

The existing artwork, typography and blue accent remain. Layout adjustments align headings, metrics, toolbars and content; improve narrow-screen header and toast containment; and preserve a visible active destination in the collapsed sidebar. Mobbin references actually inspected for this audit were [Circle](https://mobbin.com/screens/8d64bd7b-02f4-4d61-9e20-7d1174de8433) for sidebar/content alignment and [SuperHi](https://mobbin.com/screens/c0386dae-a33a-4f18-a6e4-e6540601760a) for page hierarchy. See [the design direction](production-ui-direction.md).

## Functional corrections

- Enquiry export and bulk selection follow the server's current result page. Loading failures cannot export stale rows.
- Inbox links resolve the requested conversation even when previous filters would hide it.
- Counselling rejects past booking times and future completion; the server independently enforces completion timing. An open calendar refreshes outcome controls and lists at session starts, and its day/week at Indian midnight. Booking selections become invalid as their start time passes, without requiring another interaction.
- Receipt attribution is explicit, refunds show the remaining refundable amount, and overview metrics describe the actual reporting period.
- Configuration shows actual member, enquiry, knowledge and connection counts. Recovery delays are validated.
- Billing errors and empty catalogs remain readable; restricted members receive role-appropriate guidance.
- Deferred intake loading cannot overwrite a newer workspace state. Late Meta signup callbacks are ignored after cancellation or unmount.
- HTML gateway errors produce readable retry controls; unauthorized responses still reach sign-in.
- Form labels exclude required-field decoration, and dialogs focus an available form control. Hero hover states and Help links retain readable contrast.
